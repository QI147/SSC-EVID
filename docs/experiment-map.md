# Experiment map

Every table and claim in the paper, the code path that produces it, the command that
re-creates it, and the artefact already in the repository. Line numbers are avoided
on purpose; function names are stable.

## Claims that the code does **not** support

| Claim | Status |
|---|---|
| “the method is better than every rereading strategy” | not claimed; the paper limits itself to REREAD2, SSC and independent voting |
| “each module contributes additively” | not supported: the ablation is underpowered at a 6% trigger rate, and the paper says so |
| “the gain comes from repair, not from the initial state” | not supported: the fact-first initial accounts for part of the end-to-end delta, which is why the shared-initial and ablation experiments exist |
| “units are verified” | the official relieved metric allows magnitude variants; the paper reports a unit/format sensitivity separately |

`docs/scope.md` records what was excluded from this repository and why.
